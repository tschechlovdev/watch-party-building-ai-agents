# Work only with the current branch

This repository is used in workshops. Finished solutions may exist on other branches,
tags or remotes. Solve every task from the code on the **current branch** only.

- Never read, diff, log, show, check out or merge other branches, tags or remotes
  (no `git show <branch>:…`, `git diff main..<branch>`, `git log --all`,
  `git checkout <other-branch>`, `git fetch`).
- Creating a **new** branch for your own work, and switching back to it, is fine
  (for example `git checkout -b feature/<slug>`).
